Project developed as part of the Artificial Intelligence course (2024/2025), in the second semester.

Connect Four – Adversarial Search and Decision Trees

Description 

The main objective was to develop a system capable of playing Connect Four against a human player or another algorithm, using: MCTS with UCT as a game strategy; ID3 to train a decision tree based on game states generated by MCTS;

Ability to play in three modes:

  - Human vs. Human
  - Human vs. Computer
  - Computer vs. Computer (MCTS vs Decision Trees)

Features

  - Complete implementation of Connect Four in text mode
  - MCTS with UCT and parameterization of the number of simulations
  - Generation of training dataset from MCTS games
  - ID3 algorithm to learn and play based on data
  - Discretization for numerical datasets (Iris)

Tests on two datasets:

  - iris (for ID3 validation)
  - Connect Four game states (generated via MCTS)

How to play

Make sure you are in the project directory and run: python3 play.py

Requirements

- numpy
